Projet ASG-2026

Pipeline d'assemblage de novo

Reconstruction d'une sequence consensus a partir de fragments courts (reads), sans alignement global couteux : decoupage en k-mers, alignement local par programmation dynamique, puis assemblage memory-efficient via un Filtre de Bloom (approche type Minia 2).

Lot 1

Ingestion & qualite

FASTQ → FASTA, decoupage en k-mers, histogramme de frequence.
Lot 2

Alignement (LCS)

Plus longue sous-sequence commune entre deux reads, programmation dynamique.
Lot 3

Assemblage par Bloom Filter

Traversee on-the-fly du graphe de de Bruijn conceptuel.

Jeu de donnees jouet

Une courte sequence de reference connue (300 bases), fragmentee en reads chevauchants avec un taux d'erreur de 1%, pour valider le pipeline de bout en bout (clause de recette : identite > 98% a partir des reads).
